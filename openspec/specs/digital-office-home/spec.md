# digital-office-home Specification

## Purpose

提供基于当前真实执行事实的轻量数字办公室首页，集中呈现员工、工作、人工处理和最近动态，同时复用既有聚合、SSE与任务工作台。

## Requirements

### Requirement: 数字员工办公室

首页 SHALL 以轻量固定工位呈现员工姓名、当前动作与真实运行状态，并在完整提示中提供职责与当前任务，沿用浅色背景、绿色主题和顶部导航；员工状态变化不得改变工位顺序。工作动效 MUST 仅由当前未被替代的 Session 执行事实驱动。

#### Scenario: 观察真实执行
- **WHEN** 当前 Session 正在运行且首页数据可用、连接正常
- **THEN** 对应工位显示工作状态与轻量工作动效，点击可进入当前任务工作台

#### Scenario: 当前轮结束与旧轮隔离
- **WHEN** 当前轮结束、取消或失败，或旧 Session 已被新 Session 替代
- **THEN** 首页停止旧轮的工作动效，不把业务任务仍在进行中当作 Session 正在执行，重试后只呈现当前 Session

#### Scenario: 多员工与搜索
- **WHEN** 存在多个团队或用户搜索姓名、职责、当前任务
- **THEN** 工位可通过团队与状态筛选访问，长文案保留可读摘要与完整分行提示，桌面布局可滚动访问全部员工；姓名/动作滚出视口时提示隐藏，不遮挡筛选栏

### Requirement: 人工处理直达

首页 SHALL 常驻呈现等待确认、等待输入和异常事项，并提供直接进入相应 Task Workspace 的操作；提醒文案 MUST 使用后端任务状态与人工等待原因。

#### Scenario: 等待人工与异常
- **WHEN** 任务等待原生权限确认、问题答复，或发生异常
- **THEN** 对应工位及待处理区域明确显示人工操作提示，用户可直接进入当前 Task Workspace

#### Scenario: 待处理加载失败
- **WHEN** 待处理接口不可用
- **THEN** 首页显示加载失败或上次快照提示，不声称无需人工介入，其他成功模块仍可用

### Requirement: 真实动态与恢复

首页 SHALL 展示已有业务事件构成的最近动态，并复用现有 SSE 触发聚合数据更新；当前 Session 没有产生业务事件时允许有界刷新。断线与刷新失败 MUST 明确可见，不得用前端时间推断 Runtime 终态。

#### Scenario: 事件与刷新并发
- **WHEN** 新业务事件在聚合刷新过程中到达
- **THEN** 首页合并刷新请求并随后获取最新工位、待处理与动态，避免遗漏后到事件；新完成事件先于工位空闲状态返回时，等待该工位快照更新后显示短暂完成反馈

#### Scenario: 断线重连与页面可见性
- **WHEN** SSE 断线、恢复或页面重新可见
- **THEN** 首页明确显示连接情况，在不可确认实时状态时停止工作动效，恢复后刷新现有状态，不创建新 Session

#### Scenario: 减少动态效果
- **WHEN** 用户启用减少动态效果或页面处于后台
- **THEN** 工位停止持续工作动画，业务状态与入口仍然可读
