## Context
Task 与单轮 Session 终态混用，人工确认导致会话阻塞。现有表与原生 Workspace 足够。

## Goals / Non-Goals
按用户给定流程收敛；不新增表、状态或编排，不重写原生界面。

## Decisions
- 保留现有状态枚举，Task 活跃/待处理由人工闭环，RuntimeSession 仍记录原生结果；业务终态不再被观察重开。
- 完成前在锁外核验原生空闲，再锁内重验绑定和待确认输入；旧会话/旧输入返回继续隔离。
- 原生停止只中断当前轮，Astra 终止才取消任务。
- Diff 在任务绑定工作区直接读取 Git，复用已有基线字段和文件路径校验。
- 删除后台自动复盘调度，保留手动能力；回复进行中仅观察原生状态，空闲时读取用量。

## Risks / Trade-offs
- 无公司 SSH 或实际模型凭据，真实公司环境需实测，模拟测试不算实测。
- 数据库字段保留用于现有 API；已有已完成任务不自动重开。部署仅重启服务，回滚代码即可。
