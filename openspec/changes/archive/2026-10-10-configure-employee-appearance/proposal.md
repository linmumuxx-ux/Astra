## Why

数字员工目前不能选择形象，首页与员工管理还分别按 ID 映射到两套素材，导致同一员工外观不一致。需要允许用户在新建和编辑员工时，从首页数字空间已有的九种形象中选择并保存。

## What Changes

- 新建、编辑数字员工时展示九种形象预览并支持选择，沿用现有保存与放弃修改流程。
- 员工记录持久化形象编号，员工 API 与首页聚合 API 返回相同配置；非法编号拒绝写入。
- 首页、员工列表、详情和既有办公室组件共用首页形象素材，状态改变只改变朝向与动效。
- 一次性回填已有员工当前首页形象，避免升级后首页人物变化。不新增素材、上传能力或员工自主调用工具修改配置的权限。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `digital-office-home`：新增员工形象选择、保存、统一展示和历史形象保留的要求。

## Impact

涉及数字员工模型、Alembic 迁移、员工读写 Schema、首页聚合、前端员工配置及形象展示。只新增可选写入字段及返回字段；不改变 Task、Session 或 Runtime 生命周期，不改 workspace-ui。
