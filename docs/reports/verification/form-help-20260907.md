# 表单说明与对齐检查（2026-09-07）

## 问题与调整

员工配置多个字段把说明作为 label 的第三行，导致同一 form-grid 的左右标签和控件高度不同；开关卡片中的任务分类描述长度不一。创建任务的完成策略和分配方式、系统动效偏好也存在常驻补充说明。

新增公共组件：

- `components/forms/FormLabel.vue`：统一标签与信息按钮，14px 图标、18px 按钮、5px 标签间距，颜色取主题变量。鼠标悬停/键盘聚焦显示说明，移开/失焦/Esc 隐藏；提示 Teleport 至 body，避免被表单/弹窗滚动容器裁切，并根据视口与滚动位置定位。
- `components/forms/FormField.vue`：统一字段布局与开关行，自动生成唯一控件 ID，通过 slot 传入 input/select/AstraSwitch。说明按钮独立于关联 label，不会切换开关或提交表单。
- `styles/forms.css`：统一字段标签基线与成对控件对齐，只读 ID 与可编辑控件保持同一控制行高度。

接入范围：员工基本信息、工作范围（含动态分类描述）、本地/远程工作环境、工作策略、任务创建和系统偏好。移除环境类型按钮的常驻介绍及对应的多余文字行布局；安全机制说明收进 SSH 密码、Server Port 字段提示。

保留直接展示的内容：环境检测明细、连接失败、表单校验/保存错误、实际运行状态、已选附件。字段本身的“说明/摘要”输入框、知识正文、对话业务内容、只读来源说明和页面模块介绍均保留，未改变字段含义或页面结构。

## 后续使用

有说明的普通输入项使用：

```vue
<FormField label="字段名称" help="完整补充说明" v-slot="{ id }">
  <input :id="id" v-model="value" />
</FormField>
```

开关增加 `inline`，给 AstraSwitch 传同一 `id`；只读标签可直接用 FormLabel。说明不要重新放到控件下方，也不要给各页面增加独立的图标和 Tooltip 样式。校验错误继续使用原有常驻错误区域。
