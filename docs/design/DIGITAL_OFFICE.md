# 首页数字办公室

本页是 Astra 已有执行状态的可删除展示层。Task 管理业务闭环，OpenCode Session 提供执行事实，RuntimeSession 只提供当前绑定和终态索引。办公室不创建任务、Session、Agent、数据库表或事件系统。

## 首页与视觉

旧首页通过六个 dashboard 聚合接口，展示概况卡片、员工列表、近期任务表格、人工事项、活动和知识模块；首页断开全局 SSE，依赖30秒轮询。仓库旧办公室与人物素材均不参与本次首页实现。

现在顶部集中展示在线员工、正在工作、今日完成、待处理四项核心统计及创建任务入口，中间保留连续办公室，右侧为人工事项和最近动态。无待办时使用紧凑提示，不再在页尾重复统计；保留任务中心、数字图书馆入口。

连续房间、桌椅与人物直接复用 `workbzw/ai-office-react`，将其桌/人物/椅子分层与锚点适配到 Vue DOM。人物由原始角色资源离线导出静态姿势；手动刷新模式下不播放持续工作动画，人工等待显示黄色提示并转向使用者。没有随机走动或自动演示。来源与离线脚本见 `frontend/THIRD_PARTY_NOTICES.md`。

员工保持后端顺序，状态变化不挪工位。桌面默认3列，少量员工居中，减少场景上下和横向留白；工位区域可纵向滚动，全部员工仍在DOM中可访问。团队、状态和全局搜索用于缩小范围，并提供离线/停用筛选。头顶直接显示姓名、员工可用状态、当前轮状态和任务摘要，完整任务、职责、团队保留在浅色分行提示中。提示以姓名/动作定位，限制宽度与工位视口边界；参考元素滚出视口后隐藏，不遮挡筛选栏。

## 状态映射

后端只连接 `Task.current_session_id`，同时要求 Session 的 Task、员工匹配且 `superseded_by` 为空；不探测每位员工的 OpenCode Server。

| 展示状态 | 当前事实 | 动效 |
| --- | --- | --- |
| attention | 可用员工的 Task WAITING 且有人工原因或员工 WAIT_HUMAN | 静态黄色提示；直接进入当前 Task Workspace |
| working | 当前 Session 快照 RUNNING、连接 CONNECTED、后端工位 working | 静态工作状态，不暗示实时同步 |
| waiting | 当前轮 WAITING/INTERRUPTED、员工暂停或连接不可用 | 静止并显示后端状态文案 |
| error | 当前 Task/Session FAILED 或员工 ERROR | 静态红色异常提示 |
| idle | 无任务、PENDING、当前轮 SUCCEEDED，或状态待确认 | 静止；使用后端状态文案 |
| offline / disabled | Employee OFFLINE / enabled=false | 人物降饱和，明确显示离线或已停用，不显示为正常空闲 |
| thinking | 展示接口支持，但目前没有可用的明确分析阶段事实 | 暂不从文字或计时猜测该状态 |

当前轮已结束而业务 Task 仍 RUNNING 时，工位必须静止。旧失败轮次不抢占新 PENDING 任务；历史失败仍在待处理列表。工作动作使用当前任务标题，避免旧进度摘要“等待启动”覆盖真实工作状态。

员工可用状态使用 enabled/status 快照，与 overview 的平台在线口径对应，不表示 OpenCode Server 实时连通性；执行状态继续由当前 Session 绑定事实驱动。

点击有任务的工位进入现有 `/tasks/:id`，由原任务页打开当前 Session/Workspace；无任务进入 `/employees/:id`。每个工位另有员工详情入口，有有效当前 Session 时显示进入会话，否则显示查看任务。首页创建任务链接进入任务页原有抽屉，不复制表单、问题答复或权限确认逻辑。

## 数据、动态与恢复

首页仅请求 `overview`、`employees`、`attention`、`activity` 四个原聚合接口。API 扩展当前任务绑定、人工原因和所需轻量统计；不新增独立 Office API。

管理台关闭全局 SSE 与所有数据轮询。首页只在进入页面及手动点击刷新时读取这四个聚合接口，刷新中不排队补刷；业务事件、网络恢复及切回前台都不会触发读取。平台助手和内嵌 OpenCode 自身的执行流不受影响。

首页显示“自动刷新已关闭”与工位更新时间，持续工作动画始终停止。接口失败保留上一成功快照并明确标记；首次失败显示重试。顶栏徽标复用首页 overview 的待处理计数。短暂完成反馈仅来自手动获取的新 `task_completed` 动态，首次加载历史不播；动态先于员工快照返回时，待当前工位空闲后播放一次。已处理事件 id 仅保留在当前最近动态范围内。

四个请求使用同批取消信号，15秒无响应后结束加载、保留成功模块与旧快照，释放刷新按钮；卸载页面时取消未完成请求。工位、统计和动态分别保留快照时间，失败不声称全页已更新。

最近动态只返回目标仍存在的业务事件，避免已删除任务或员工产生失效链接。前端只合并相邻且员工、目标、类型和描述一致的事件，保留最新时间、目标与次数；不同结果、不同员工、被中间事件分隔的记录保持独立。

## 范围与回滚

重点验证1280、1440、1920桌面宽度；窄屏使用已有组件自然换行与单列侧栏，不新增专用页面。

主要文件为 `DashboardView.vue`、`components/home/`、`features/home/`、dashboard聚合与顶部徽标。还包含开源素材和对应回归测试。

关闭自动刷新只涉及管理台前端，可回退对应前端改动；没有数据库迁移，未修改 Task/Session/Runtime 生命周期或 workspace-ui 源码。

验收结果与截图见 `evidence/digital-office-home-20261001/README.md`。
