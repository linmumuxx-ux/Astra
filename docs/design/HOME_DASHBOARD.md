# NEXUS 首页数据看板

## 定位

首页是数字空间状态总览与专业页面入口，不承担员工配置、任务处理或知识维护。原“数字办公室”方案已退出首页，源码快照保存在 `docs/archive/digital-office-20260905/`，后续如需恢复应作为独立页面或实验路由评估。

## 页面模块

- 无卡片的运行摘要：数字员工、工作中、待处理任务、需要关注
- 以数字员工为主体的团队空间，保留大头像、状态和当前任务
- 可直接进入处理的最近五项阻塞事项
- 统一运行信息区中的最近任务和最近动态
- 展示今日沉淀、候选经验和最近知识的数字图书馆场景

首页只展示业务摘要，不展示模型、Prompt、Skill、Workspace、Server、MCP、Shell、stdout、Git、SSE 或 Token 明细。

## 数据接口

首页使用六个独立聚合接口：

- `GET /api/dashboard/overview`
- `GET /api/dashboard/employees`
- `GET /api/dashboard/attention`
- `GET /api/dashboard/tasks`
- `GET /api/dashboard/activity`
- `GET /api/dashboard/knowledge`

各模块独立请求和处理失败，单一接口异常不会阻断整个首页。员工状态统一映射为“执行中、空闲、等待、异常”，待关注状态统一映射为“执行失败、任务阻塞、等待处理、异常”。任务聚合接口同时返回最近任务，知识聚合接口同时返回最近三条可见知识，首页不为这些列表额外请求专业页面明细。

## 刷新策略

- 进入首页时请求一次全部聚合数据。
- 支持右上角手动刷新。
- 前台每 30 秒自动刷新；页面进入后台后暂停，恢复可见时按需补刷新。
- 首页不连接全局任务事件流，也不订阅任何 Workspace Stream。

## 跳转约定

- 摘要和员工跳转到数字员工管理、筛选结果或员工详情。
- 待处理事项提供明确“处理”入口，最近任务和动态跳转到任务详情。
- 最近知识可打开知识详情，场景入口跳转到数字图书馆。

## 页面状态

所有模块均具备 Skeleton、明确空状态和模块级错误提示。首页不再重复展示产品名或“空间概览”标题，也不使用五张 KPI 卡和低数据量趋势图。页面只保留五个主要区域：数字员工、需要处理、最近任务、最近动态、数字图书馆；其中数字员工与需要处理采用约 7:5 的核心区比例。

视觉使用 `#16332B` 深绿作为骨架、薄荷绿作为品牌和运行状态、琥珀色表示等待、珊瑚红表示失败或异常。员工头像保持人物存在感，团队聚合只用一句弱提示，不拆成多组彩色统计。

当前版本只以桌面 Web 为设计与验收范围，不新增移动端适配诉求。
